🛒 DMart Sales Analytics  Dashboard
📊 Project Overview

This project presents an interactive DMart Sales Analysis Dashboard developed to analyze sales performance, revenue, profit, product categories, customer segments, and regional performance.

The dashboard transforms raw sales data into meaningful business insights using interactive KPIs and visualizations.

🎯 Project Objective

The main objective of this project is to analyze DMart's sales data and understand:

Overall revenue and profit performance
Sales and profit trends over time
Performance of different product categories
Regional and city-wise sales performance
Customer and order patterns
Products/categories contributing the most to revenue and profit
Areas where business performance can be improved
📁 Dataset

Dataset: DMart Sales Dataset

The dataset contains sales-related information used to create the dashboard and perform the analysis.

Key Data Fields

The analysis includes fields related to:

Order / Transaction information
Date
Product Category
Product / Sub-Category
Customer information
Location / Region
Sales / Revenue
Quantity
Profit
Other sales-related attributes

The original Excel dataset is included in this repository.

📄 Dataset File: DMart Sales Dataset.xlsx

📌 Key Performance Indicators (KPIs)

The dashboard provides important business KPIs such as:

💰 Total Revenue

Shows the total revenue generated from all sales transactions.

📈 Total Profit

Shows the overall profit generated from the sales.

🛍️ Total Sales / Orders

Represents the overall sales activity recorded in the dataset.

📦 Total Quantity

Shows the total quantity of products sold.

📊 Average Sales

Measures the average sales value across transactions.

These KPIs provide a quick overview of the overall business performance.
